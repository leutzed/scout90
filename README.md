# Scout90

Painel de scouting de futebol com filtros, rankings por perfil, gráficos de comparação e lista de observação. O arquivo index.html inclui a base original e pode ser aberto diretamente em um navegador.

As fichas, anotações, bases importadas e escolhas de ocultação ficam armazenadas no navegador. O painel aceita novas exportações em JSON ou TXT pelo botão **Importar base**.
